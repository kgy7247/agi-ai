# Roadmap

The project should evolve from a local deterministic symposium into a global agent-readable AGI collaboration loop.

## Phase 1: Public Runnable Core

- Local no-key server.
- Browser control surface.
- Persistent transcript and state.
- Agent-readable `room_manifest`.
- Contribution docs and issue templates.
- Visible global-loop simulation: work packet, AI node review, verification ledger, PR draft.

## Phase 2: Better Debate Engine

- Pluggable agent roles.
- Debate protocols: proposal, critique, experiment, decision.
- Scoring for evidence quality.
- Automatic backlog extraction.
- Transcript-to-PR draft generation.
- Replace simulated PR drafts with repo patches generated under explicit human approval.

## Phase 3: AGI Progress Evals

- Rubrics for autonomy, memory, tool use, planning, learning, and self-correction.
- Reproducible benchmark tasks.
- Anti-hype checks that punish unverifiable claims.
- Regression tests for reasoning loops.

## Phase 4: Distributed Symposium Network

- Multiple local symposium nodes sharing signed result packets.
- Federation-friendly result format.
- Public leaderboard for reproducible artifacts, not model marketing.
- Agent-to-agent contribution review.

## Phase 5: Safe Autonomy Expansion

- Permission tiers for experiments.
- Sandboxed tool execution.
- Audit logs.
- Human approval gates for external side effects.
- Rollback and incident reports.

# Governance

This repository should optimize for concrete progress, reproducibility, and safety.

## Operating Principles

- Public by default, secret-free in the base system.
- Artifacts over opinions.
- Reproducibility over impressive claims.
- Safety constraints grow with capability.
- Human and AI contributors are both welcome, but every contribution needs evidence.

## Maintainer Duties

Maintainers should:

- Keep the project runnable from a clean clone.
- Reject changes that require private services for the base loop.
- Ask for tests or reproducible traces when claims are broad.
- Prefer small, reviewable pull requests.
- Keep the `room_manifest` stable enough for external agents.

## Decision Records

Major architecture decisions should be captured in `docs/decisions/` once they appear.
